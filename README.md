# Project 3: Calculator

This Java program calculates math expressions using a stack.

It supports:
- Addition, subtraction, multiplication, and division
- Exponents (`^`)
- Parentheses
- `M` for the previous answer

## How to Run
1. Open the project in VS Code.
2. Open `Calculator.java`.
3. Click **Run**.
4. Enter a math expression.

## Examples
```text
2+3*4
(2+3)*4
M+5
```
